코리아식품 수율 일지 · 사내 서버 설치 안내

회사 PC 한 대에 설치하면, 같은 와이파이에 연결된 태블릿·휴대폰·PC가 인터넷 주소처럼 접속해서 함께 씁니다. 사이트에 들어가면 로그인 화면이 나오고, 직원마다 아이디와 비밀번호로 로그인합니다. 다른 사이트 가입은 필요 없습니다.

준비물
  • 근무 시간에 항상 켜 두는 윈도우 PC 1대 (사무실 PC면 충분합니다)
  • 태블릿과 그 PC가 같은 공유기(와이파이)에 연결되어 있을 것
  • 이 폴더 (KoreaFood-Yield-Server)

1파이썬 설치 (처음 한 번)

  1. python.org/downloads 에 들어가 노란색 Download Python 버튼을 누릅니다.
  2. 받은 파일을 실행하고, 첫 화면 아래의 “Add python.exe to PATH” 에 꼭 체크한 뒤 Install Now 를 누릅니다.
  3. 설치가 끝나면 닫습니다. 다른 프로그램은 설치하지 않아도 됩니다.

2폴더 놓기

받은 압축 파일을 풀어 C:\KoreaFood-Yield-Server 처럼 찾기 쉬운 곳에 둡니다. 바탕화면보다는 C 드라이브 바로 아래를 권합니다. 이 폴더 안에 데이터가 쌓이므로 지우거나 옮기지 마세요.

3서버 켜기

  1. 폴더 안의 server.py 를 두 번 누릅니다. (start.bat 이 들어 있으면 그걸 눌러도 됩니다.)
    “이 파일을 열 앱”을 물으면 Python 을 고르세요.
  2. 검은 창이 뜨고 “사내 서버가 켜졌습니다”와 함께 주소가 나옵니다. 예: http://192.168.0.15:8080
  3. 처음에 Windows 보안 경고(방화벽) 창이 뜨면 “개인 네트워크” 에 체크하고 액세스 허용을 누릅니다. 이걸 허용해야 태블릿에서 접속됩니다.
검은 창을 닫으면 서버가 꺼집니다. 최소화(—)해서 두세요. 매번 켜기 번거로우면 8단계로 자동 실행을 걸어 두세요.

4처음 설정 (관리자 계정 만들기)

  1. 그 PC에서 크롬이나 엣지를 열고 주소창에 http://localhost:8080 을 입력합니다.
  2. “처음 설정” 화면에서 관리자 아이디(영문·숫자), 이름, 비밀번호(4자 이상)를 정합니다. 이 아이디로 관리자 화면(기준값·보고서·백업)에 들어갑니다.
  3. 관리자 화면의 기준·백업에서 제품별 기준 수율, 원료육 단가, 사업장(코리아식품·하비랑)을 확인·수정합니다.

5태블릿에서 접속

  1. 태블릿이 회사 와이파이에 연결되어 있는지 확인합니다.
  2. 크롬(또는 사파리)을 열고, 검은 창에 나온 “태블릿·다른 PC” 주소를 입력합니다. 예: http://192.168.0.15:8080
  3. 자주 쓰니 홈 화면에 추가해 두세요. (크롬: 오른쪽 위 ⋮ → 홈 화면에 추가 / 사파리: 공유 버튼 → 홈 화면에 추가)

6직원 계정 · 로그인

  • 관리자가 만들기: 기준·백업 → 직원 · 로그인에서 아이디, 이름, 비밀번호, 역할(현장/관리자)을 넣고 “계정 만들기”를 누릅니다.
  • 직원이 직접 가입: 로그인 화면의 “회원가입”에서 아이디, 이름, 비밀번호를 정합니다. 직접 가입을 막으려면 config.json 의 "allow_self_register" 를 false 로 바꾸세요.
  • 비밀번호를 5번 틀리면 30초 동안 잠기고, 30분 동안 쓰지 않으면 자동으로 로그아웃됩니다(관리자가 바꿀 수 있음).
  • 비밀번호를 잊으면 관리자가 같은 화면에서 새 비밀번호를 정해 줍니다.

7PC 주소 고정 (권장)

공유기가 PC 주소를 가끔 바꾸면 태블릿에 저장한 주소로 접속이 안 됩니다. 공유기 관리 화면에서 이 PC에 고정 IP(DHCP 예약)를 걸어 두면 주소가 바뀌지 않습니다. 회사 전산 담당자나 공유기 업체에 “서버 PC 고정 IP 설정”을 요청하면 됩니다.

8PC 켤 때 자동 실행

서버 창을 닫은 뒤, 폴더 주소창에 cmd 를 입력해 엔터 → py server.py --autostart 를 입력하면 다음부터 PC를 켤 때 서버가 자동으로 (최소화된 창으로) 켜집니다.

9백업 · 복원

  • 서버가 하루 한 번 backup 폴더에 자동 백업합니다(.db 파일과 사람이 읽을 수 있는 .json 파일). 30일 지난 백업은 자동으로 지웁니다.
  • NAS에 백업하려면 메모장으로 config.json 을 열어 "backup_dir" 를 NAS 폴더로 바꾸고 서버를 다시 켭니다.
    예: "backup_dir": "\\\\NAS\\공유폴더\\수율백업"
  • 복원: 서버 창을 닫고 → data 폴더의 yield.db 를 다른 이름으로 바꿔 둔 뒤 → 백업한 yield-날짜.db 를 data 폴더에 복사해 이름을 yield.db 로 바꾸고 → 서버를 다시 켭니다.
  • 관리자 화면의 “전체 백업(.json)” 버튼으로 언제든 직접 내려받을 수도 있습니다.

10문제가 생기면

증상확인할 것
server.py를 눌러도 아무 일이 없거나 “파이썬이 설치되어 있지 않습니다”1단계를 다시 하되 “Add python.exe to PATH” 체크를 꼭 확인하세요. 설치 후 PC를 다시 시작하면 확실합니다.
“포트 8080을 이미 쓰고 있어…”서버 창이 이미 열려 있는지 작업 표시줄을 확인하세요. 다른 프로그램이 쓰고 있으면 config.json 의 "port" 를 8090 등으로 바꾸고, 접속 주소도 :8090 으로 바꿉니다.
PC에서는 되는데 태블릿에서 접속이 안 됨① 태블릿이 같은 와이파이인지 ② 서버 창이 켜져 있는지 ③ 방화벽 허용(3단계)을 했는지 ④ 주소의 숫자가 검은 창에 나온 것과 같은지 확인하세요.
화면 위에 “저장 대기 N건”이 뜸잠시 연결이 끊긴 상태입니다. 입력값은 태블릿에 보관되어 있다가 연결되면 자동으로 저장됩니다. 계속 남아 있으면 서버 창이 켜져 있는지 확인하세요.
관리자 비밀번호를 잊음다른 관리자가 있으면 그 사람이 새 비밀번호를 정해 줍니다. 관리자가 한 명뿐이면 서버 PC에서: 서버 창을 닫고 → 이 폴더의 주소창에 cmd 를 입력해 엔터 → py server.py --reset-password 아이디 새비밀번호 를 입력합니다. 그다음 server.py로 다시 켜세요.
